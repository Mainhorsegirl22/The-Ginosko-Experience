Making things fill themselves in

Your base is already built so that the Reservation is the center of every puppy deal. This guide teaches you the two tools that make everything else — the puppy, the pickup, the training — appear automatically around it, without retyping anything.

Start here

Two tools, and they do different jobs

Almost everyone reaches for an "automation" when half the time they actually want a lookup. Getting this distinction right saves you the most work, so it comes first.

Lookup field

Show something already linked

A lookup reaches across a link you already have and displays a value from the other table. It updates on its own, instantly, forever. No setup to maintain.

Use it for: the reserved puppy's name showing on the Pickup, the client's town showing on the Calendar, the litter's go-home date showing on the Reservation.

Automation

Do something when a thing happens

An automation watches for a moment — a record created, a box checked — and then acts: create a record, fill a field, make a calendar event, send an email.

Use it for: creating a Training Assignment the instant a reservation asks for training, or marking a puppy "Reserved" the moment it's attached to a deal.

💡

The quick test: if you just want to see information that lives on a linked record, that's a lookup — no automation needed. If you want the system to create or change a record for you, that's an automation.

The shape of every automation

When this happens → do that

Every automation in Airtable, no matter how fancy, is just a trigger followed by one or more actions. Once you see this shape, they all read the same.

When — the trigger
Something happens A record is created, a field changes, a checkbox is ticked, or a scheduled time arrives.
→
Then — the action
Airtable does a thing Update a record, create a record, find records, or send it to Google Calendar.

You'll find all of this under the Automations button in the top bar of your base. Each automation has an on/off switch, and — importantly — a Test button you run before you ever turn it on.

Recipes for your base

Four things worth setting up

These are built from the tables you already have. Two are lookups (a few clicks, no risk), two are true automations. Do them in this order — each one teaches the click-path for the next.

RECIPE 01

Show the reserved puppy everywhere Lookup

The Reservation already links to a Puppy. To make that puppy appear on the Pickup & Delivery record (and anywhere else), add a lookup that borrows it through the link — no automation involved.

  1. Open the Pickup and Deliveries table and click the + to add a field.
  2. Choose field type Lookup.
  3. For "which link," pick the existing Reservation link on that table.
  4. For "which field to pull," choose Puppy. Name the field Reserved Puppy and save.
  5. Repeat the same steps on any table where you want the puppy visible — the Litter, the Calendar view, the Training Assignment.
🔗

This is also the real answer to "the puppy isn't linked to the reservation." The link is there — I checked your live records. What's missing is it being shown on the other screens. Lookups fix that without changing a single relationship.

RECIPE 02

Put pickups on the calendar from the Litter page Lookup + Automation

Your Pickup table already has a Calendar Title formula, a Calendar Start (text), and a Send to Calendar checkbox — the plumbing for calendar sync is in place. Here's the piece that pushes it out.

  1. In Automations, click Create automation and name it "Pickup → Google Calendar."
  2. Trigger: When a record matches conditions → table Pickup and Deliveries, condition Send to Calendar is checked.
  3. Action: Google Calendar → Create event (connect your calendar once when asked).
  4. Map the event Title to Calendar Title, and both Start and End to Calendar Start (text) — the field notes even tell you to use these.
  5. Run Test, confirm the event previews correctly, then flip the automation On.

To schedule from the Litter page: the Litter already links to its Pickups, so add each pickup there; the checkbox is what actually sends it. Add a Reserved Puppy lookup (Recipe 01) on the Pickup so the calendar event shows which puppy it's for.

RECIPE 03

Mark a puppy "Reserved" the moment it's attached Automation

So a puppy's own status keeps itself honest without you remembering to change it.

  1. New automation: "Puppy attached → mark Reserved."
  2. Trigger: When a record is updated → table Reservation, watched field Puppy.
  3. Add a condition so it only runs when Puppy is not empty (skips blank waiting-list rows).
  4. Action: Update record. For the record to update, choose the Puppy from the trigger step.
  5. Set that puppy's Status to Reserved. Test with one real reservation, then turn it On.
RECIPE 04

Auto-create a Training Assignment from the Reservation Automation

When a reservation asks for training, spin up the Training Assignment already linked back — no re-entry.

  1. New automation: "Reservation wants training → make assignment."
  2. Trigger: When a record matches conditions → table Reservation, condition Training Type is not empty.
  3. Action: Create record → in the Training Assignments table.
  4. Set its Reservation link to the record from the trigger step. Because Puppy and Trainer flow through that link, they fill in on their own.
  5. Test, then On. Now every training reservation lands as a real assignment automatically.

Before you trust it

Testing without touching real data

🧪

Golden rule: an automation stays Off until you've run Test and read what it says it will do. Airtable shows you the exact record it's about to change before anything happens. Test first, every time.

Three things that keep you safe:

  1. Automations don't run backwards. Turning one on only affects records changed from that point forward — it won't sweep through your whole history.
  2. The run log is your receipt. Each automation keeps a history of every time it fired and what it touched. If something looks off, open it and read the last run.
  3. Duplicate the base before big changes. For anything you're nervous about, right-click the base → Duplicate, and practice there first. Your real data stays untouched.
